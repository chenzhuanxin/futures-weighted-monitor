加权（仓权）合约监控面板

跑在本机的期货全品种监控看板：86 个品种的加权（仓权）合约行情， 对照历史最高 / 最低 / 均价算出偏离度，配动态均线阈值 + 偏移 + 锁定， 触发时只发卡片式邮件。Python + HTML，全部离线可用。

⬇ 下载 exe（91 MB） 使用说明 源码仓库
⚠ 本面板仅为个人学习研究工具，行情存在延时，不构成任何投资建议， 据此交易风险自负。行情数据版权归上海信易信息科技股份有限公司（天勤 / 快期）所有。

它解决什么问题

看单个合约（尤其主连）容易被换月跳空和流动性差异干扰。加权合约按持仓量加权 合成指数，更贴近品种整体价格水平。面板把「当前价距历史极端位置有多远」量化成 0~100 的偏离度，横向铺开 86 个品种，一眼看出谁在高位、谁在低位。

加权（仓权）合约

KQ.i@ 口径

天勤官方指数合约，按持仓量加权，换月平滑无跳空。不使用主连 KQ.m@。

偏离度

历史位置量化

以历史均价 M 为 0 基准，高低两侧各自归一化到 0~100，越大越极端。

动态阈值

均线 + 偏移 + 锁定

周期 × 均线二级选择填充，0.1%~1% 上/下偏移，锁定后才预警，门槛 60~90% 可调。

预警

1 分钟 K 线穿越

上一根在阈内、当前根穿越到阈外才触发；同一根 K 线只报一次，不刷屏。

快速开始

两种方式，任选其一。

方式 A · exe（推荐）

双击 加权合约监控面板.exe
→ 等几秒（解压 91MB 包体）
→ 浏览器自动打开看板
→ 右上角「设置」填天勤账号与邮箱，即可开始监控

方式 B · 源码

pip install tqsdk
双击 启动面板.bat
# 或：python launch.py

启动后控制台会打印「看板地址」（默认 http://127.0.0.1:8962/ ，端口被占会自动顺延）。 控制台窗口不能关，关闭即退出服务。

技术要点

服务端

Python 标准库实现 HTTP + SSE + 预警引擎 + 配置持久化，唯一第三方依赖是 tqsdk。

行情层

独立线程持 TqApi 循环 wait_update()，外部通过任务队列投递请求，线程安全。

前端

原生 HTML/CSS/JS，SSE 事件驱动局部更新，无轮询；ECharts 已本地化，离线可用。
