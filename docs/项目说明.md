# 项目说明

> 加权（仓权）合约监控面板 · 天勤 TqSdk 版
> 一个跑在本机的期货全品种监控看板：86 个品种的**加权（仓权）合约**行情，对照历史
> 最高 / 最低 / 均价算出**偏离度**，配**动态均线阈值 + 偏移 + 锁定**，触发时发**卡片式邮件**。

---

## 一、这个项目解决什么问题

看单个合约（尤其主连）容易被换月跳空、个别合约流动性差等问题干扰。加权合约按
**持仓量加权**合成一个「指数」，更贴近品种整体价格水平。

本面板把「**当前价格距离历史极端位置有多远**」这件事量化成 0~100 的偏离度，横向铺开
86 个品种，一眼看出**谁在高位、谁在低位**；再配合动态均线阈值做**穿越预警**，盯住
关键位置的突破。

适合：期货交易者、研究员、需要同时扫全市场的资金管理人。

## 二、核心特性

| # | 特性 | 说明 |
|---|---|---|
| 1 | **只用加权（仓权）合约** | 天勤官方指数合约 `KQ.i@交易所.品种`，按持仓量加权；源码中不使用主连 `KQ.m@` |
| 2 | **偏离度口径** | 以历史均价 M 为 0 基准，高侧 `(现价−M)/(H−M)×100`，低侧 `(M−现价)/(M−L)×100` |
| 3 | **品种行情页** | 每卡片「📊 查看行情」→ 加权 + 全部真实月份合约，8 周期 × 7 类指标 |
| 4 | **动态均线阈值** | 周期 × 均线二级选择 → 填充；偏移 0.1%~1% 上/下；锁定才预警；门槛 60%~90% 可调 |
| 5 | **卡片式邮件预警** | 只发邮件，无弹窗/无声音；126 SMTP SSL → QQ 收件 |
| 6 | **非交易时段静默** | 以行情新鲜度判定（末笔 ≤300 秒 = 交易中），自动适配夜盘/周末/节假日 |
| 7 | **跟随行情刷新** | SSE 事件驱动推送，无定时轮询；实时显示数据延时 |
| 8 | **1 分钟 K 线穿越判定** | 上一根在阈内、当前根穿越到阈外才触发；同一根 K 线只报一次 |
| 9 | **可视化配置** | 设置抽屉：账号、SMTP、门槛、默认周期/均线/偏移、冷却与配额 |
| 10 | **现代 UI** | 卡片双栏、渐变进度条、阈值刻度线、触发徽标、浅/深主题、抽屉设置 |
| 11 | **一键隐身** | `Ctrl+Z` 整页切换为普通《通知》文档（标题同步改变），再按恢复 |

## 三、技术架构

### 3.1 组件与职责

```
┌──────────── 浏览器（看板 / 行情页）────────────┐
│  静态/看板.html · 看板.js · 看板.css            │
│  静态/行情.html · 行情.js · echarts.min.js      │
└───────────────▲ SSE 事件流 ────────────────────┘
                │
┌───────────────┴────────────────────────────────┐
│  服务端.py   HTTP + SSE + 预警引擎 + 持久化    │
│      │            │            │               │
│  品种表.py   天勤行情.py    邮件预警.py         │
│  (93 品种)   (tqsdk 线程)   (SMTP 卡片邮件)     │
└───────────────────────────────────────────────┘
                │  TqApi (wss)
        ┌───────▼────────┐
        │  天勤行情服务器  │
        └────────────────┘
```

| 文件 | 职责 |
|---|---|
| `服务端.py` | HTTP 服务 + SSE 推送 + 预警引擎 + 配置/阈值落盘（服务端本身只用标准库） |
| `天勤行情.py` | tqsdk 数据层：独立线程持 `TqApi` 循环 `wait_update()`，外部经任务队列投递请求 |
| `品种表.py` | 93 品种数据：代码 / 中文名 / 交易所 / 加权合约 / 历史 H-L-M |
| `邮件预警.py` | 生成并发送卡片式 HTML 邮件（内联样式，兼容 QQ / 126 / 微信邮箱） |
| `环境自检.py` | 源码运行态的自愈：自动挑装了 tqsdk 的解释器重启自己，必要时自动 pip |
| `launch.py` / `启动面板.bat` | 源码方式启动器 |
| `打包/` | PyInstaller 配置、打包入口、图标生成脚本与图标文件 |

### 3.2 数据流

1. **订阅**：启动时按品种表批量订阅加权合约的 tick 与多周期 K 线
2. **计算**：服务端每轮用最新价重算偏离度、动态阈值、门槛状态
3. **推送**：计算完成 → SSE 推 `data` 事件 → 前端局部更新（无整页刷新）
4. **判定**：每根 1 分钟 K 线闭合时做穿越检查 → 触发 → 发邮件 → 记日志

### 3.3 设计取舍

| 决策 | 原因 |
|---|---|
| 服务端纯标准库、只有 tqsdk 一个第三方依赖 | 降低部署与打包复杂度 |
| 行情层用**线程**而非进程 | 共享内存简单；打包时免去 `multiprocessing` 冻结引导的坑 |
| 预警用**纯穿越**判定 | 从机制上杜绝「长期在阈外反复轰炸」；代价是锁定时价已在阈外需先回落 |
| 前端不设轮询定时器 | 行情驱动，避免无意义请求；延时由数据自身时间戳算出 |
| 中文模块名 + ASCII 入口名 | 保持项目原有可读性；同时规避 cmd / 打包工具处理中文路径的隐患 |

## 六、为什么用加权合约而不是主连

| 对比 | 主连 `KQ.m@` | 加权（仓权）`KQ.i@`（本项目） |
|---|---|---|
| 合成方式 | 拼接主力合约片段 | 按**持仓量加权**合成 |
| 换月影响 | 换月瞬间跳空，历史曲线不连续 | 权重平滑过渡，曲线连续 |
| 代表含义 | 最活跃合约价格 | 品种**整体**价格水平（更接近指数） |
| 适用场景 | 看单合约盘口 | 看品种**位置与趋势**（本项目用途） |

本项目的偏离度是拿「现价」去跟「历史 H/L/M」比，用加权合约能最大程度减少合约
个体差异带来的噪声。

## 七、界面速览

**主看板**：顶栏（数据源 / 延时 / 主题 / 隐身 / 设置）+ 统计卡（总品种、高于均值、
低于均值、已锁定阈值、触发中）+ 左右两栏卡片（高于均值红框 / 低于均值绿框）。

每张卡片含：品种名与交易所、现价与涨跌、偏离度徽章、渐变进度条（带上下阈刻度线）、
阈值配置区、📈 合约均线查看（默认折叠）、📊 查看行情按钮。

**行情页**：合约选择条（加权居首，真实合约按持仓量排序，主力标橙点）+ K 线图上方
MA 数值条（MA5/10/20/30/60，随周期与合约跟随）+ 指标勾选 + 底部「全部合约行情」
表格（点行切换图表）。
