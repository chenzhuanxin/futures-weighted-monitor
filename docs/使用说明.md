# 使用说明

> 加权（仓权）合约监控面板 · 详细操作手册
> 从「第一次打开」到「配置好预警邮件」，按本文顺序走一遍即可。

---

## 一、启动面板

### 1.1 exe 版（推荐，免安装）

双击 `加权合约监控面板.exe`。

* 会弹出黑色控制台窗口，**不要关**，关掉就等于退出服务
* 首次启动 / 每次启动都要解压 91 MB 包体到临时目录，窗口会停顿几秒，属正常
* 服务就绪后会自动打开浏览器到看板地址
* 想停止：在控制台按 `Ctrl+C`，或直接关闭窗口

### 1.2 源码版

双击 `启动面板.bat`。它会自动挑出本机**装了 tqsdk 的那个 Python** 来跑服务端
（本机常装多个 Python，PATH 里排前面的未必装了 tqsdk）。

命令行等价方式：

```bash
python launch.py                                # 同双击 bat
python 服务端.py --port 9000 --no-browser       # 跳过启动器直接跑
```

固定解释器：

```bat
set PY_EXE=C:\Python314\python.exe
启动面板.bat
```

### 1.3 命令行参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port N` | 8962 | 起始端口；被占则自动顺延（8963、8964…） |
| `--no-browser` | 关 | 启动后不自动打开浏览器 |
| `--force` | 关 | 忽略单实例检测，强制再起一个（仅调试用） |

> **端口以控制台打印的「看板地址」为准**，不要想当然认为一定是 8962。

### 1.4 单实例保护

启动时若探测到**已有本面板实例在跑**，不会重复启动第二个，而是直接打开已有面板后退出。

* 为什么：多个实例会各跑一份行情订阅，且共用同一份阈值文件互相覆盖，导致
  「在这个页面设了阈值、在另一个页面看不到 / 不预警」
* 想开第二个：加 `--force`（仅建议调试时使用）

## 二、首次配置

### 2.1 天勤账号

1. 到 [account.shinnytech.com](https://account.shinnytech.com) 免费注册
2. 点看板右上角「设置」打开抽屉，填写**账号**与**密码**
3. 保存后自动重连；顶栏「数据源」显示 `天勤 TqSdk · 加权（仓权）合约 KQ.i@`

未配置时页面会提示「未配置天勤（快期）账号或密码」，此时无行情。

### 2.2 邮件配置（用于预警）

推荐 **126 邮箱发信 → QQ 邮箱收信**。

获取 126 授权码：

1. 登录 126 网页版 → 设置 → POP3/SMTP/IMAP
2. 开启 SMTP 服务
3. 按提示生成**授权码**（不是邮箱登录密码），复制保存

在设置抽屉填写：

| 字段 | 示例 |
|---|---|
| SMTP 服务器 | `smtp.126.com` |
| 端口 | `465` |
| SSL | 开 |
| 发件账号 | `yourname@126.com` |
| 授权码 | 上一步生成的授权码 |
| 发件人名称 | 自定义，如「期货监控」 |
| 收件人 | 可多个，回车分隔 |
| 抄送 | 可选 |

填完点「**发送测试邮件**」，收到即为配置成功。

### 2.3 面板参数

| 项 | 默认 | 说明 |
|---|---|---|
| 门槛 | 70%（可调 60~90） | 偏离度达到该值才高亮、参与预警 |
| 默认周期 / 均线 | m5 / MA20 | 填充均线时的初始选择 |
| 默认偏移 | 0.3% | 填充时的默认偏移比例 |
| 冷却 | 300 秒 | 同一品种两次预警的最小间隔 |
| 配额 | 12 封/小时、60 封/天 | 超出抑制并记日志 |

> 所有配置保存在 `缓存/配置.json`，重启后保留。

## 三、看板功能详解

### 3.1 顶栏

| 元素 | 说明 |
|---|---|
| 数据源 | 显示当前行情来源与合约口径 |
| 延时 | 现价时间戳与本机时间之差 |
| 主题 | 浅色 / 深色切换 |
| 隐身 | 或按 `Ctrl+Z` |
| 设置 | 打开设置抽屉 |

### 3.2 统计卡

| 卡片 | 说明 |
|---|---|
| 总品种 | 当前有行情的品种数 |
| 高于均值 | 现价 ≥ 历史均价的品种数 |
| 低于均值 | 现价 < 历史均价的品种数 |
| **已锁定阈值** | 可点击：列出锁定了阈值的品种，行内可**解锁** |
| **触发中 / 门槛** | 可点击：列出正在触发或达门槛的品种，行内可**解锁** |

### 3.3 品种卡片

* **框色**：高于均值 = **红框**；低于均值 = **绿框**（触发中/达门槛用外发光表达，不改变框色）
* **偏离度徽章**：高栏红、低栏绿；达到门槛变橙色实底
* **进度条**：显示该侧偏离比例，条上同时画出**下阈（绿）**与**上阈（红）**刻度线
* **阈值胶囊**：实时显示 `●已锁定 / ○已解锁 / 未配置`

### 3.4 隐身（Ctrl+Z）

按下后整页切换为一页普通《通知》文档，**浏览器标签标题同步改变**；再按一次恢复面板。

## 四、配置阈值（核心功能）

### 4.1 操作步骤

1. 找到偏离度 ≥ 门槛的卡片
2. 点「**下阈 / 上阈**」切换要配置的方向
   （两栏都可随时切换；上下阈可**同时存在、同时锁定**）
3. 选**周期**：1分 / 5分 / 15分 / 30分 / 60分 / 120分 / 日K
4. 选**均线**：MA5 / MA10 / MA20 / MA30 / MA50 / MA60 / MA80
5. 选**偏移量**：0.1% / 0.2% / 0.3% / 0.5% / 0.8% / 1%
6. 选**偏移方向**：上偏移 / 下偏移
7. 点「**填充均线**」—— 服务端按「该周期最近 N−1 根收盘 + 当前实时价」算出动态均线，
   再做 `现价 × 偏移%` 的上/下偏移，写入当前选中的阈值
8. 点「**锁定**」—— **只有锁定后才参与预警**

### 4.2 重要口径

> **填充均线时，基准恒为加权合约。**
> 卡片里的「📈 合约均线查看」只是让你**看**其他真实合约的均线数值，
> **不会**影响阈值计算，也不参与预警。

### 4.3 动态特性

阈值**不是**一个固定数字：每个 tick 都用最新价重算，随行情变化。
这也是为什么叫「动态均线阈值」。

### 4.4 语义

| 阈值 | 含义 |
|---|---|
| **下阈** | 价格**跌破**它时预警（1 分钟 K 线下穿） |
| **上阈** | 价格**上穿**它时预警（1 分钟 K 线上穿） |

### 4.5 门槛

只有偏离度 ≥ 门槛（默认 70%，60~90 可调）的品种才：

* 卡片高亮显示
* 阈值可被锁定并参与预警

## 五、📈 合约均线查看（仅供查看）

* **位置**：每张卡片内，「配置上下阈」之下、「📊 查看行情」之上
* **默认折叠**：点一下折叠条展开，展开后自动查询加权合约
* **三级选择**：标的（加权 / 任一真实月份合约） × 周期 × 均线（MA5/10/20/30/60）
* **显示内容**：
  * 主值：该周期已收 K 线算出的均线值
  * 实时值：把末根 K 线的收盘换成实时价重算的值
  * 现价与涨跌、价相对均线的偏离、行情时间
  * 下方一排胶囊列出该周期**全部常用均线**，点胶囊即切换主显示
* **不参与阈值计算**

## 七、历史基准 H / L / M

### 7.1 导出

设置抽屉 → 「导出历史基准」→ 下载 `基准HLM_日期.json`，含当前生效的全部品种 H / L / M。

### 7.2 导入

设置抽屉 → 「导入」→ 选择之前导出的 JSON 文件。导入值**覆盖**内置值，
卡片上 `baseSrc` 显示为 `import`。

### 7.3 恢复内置

点「恢复内置」或删除 `缓存/基准_HLM.json` 即可回到「Excel + 自动计算」。

## 八、预警机制

### 8.1 判定链路

```
行情新鲜度检查（末笔 ≤300 秒）
        ↓ 交易中
1 分钟 K 线穿越检查（上一根在阈内 → 当前根在阈外）
        ↓ 命中
同根 K 线只报一次
        ↓
同品种冷却（300 秒）
        ↓
配额检查（12/小时、60/天）
        ↓
发送卡片式邮件 → 记日志
```

### 8.2 收不到邮件的排查顺序

1. 设置抽屉点「发送测试邮件」，看返回信息
2. 查垃圾邮件 / 广告邮件箱
3. 检查授权码是否失效（126 网页版重新生成）
4. 看「预警日志」是否有「已发送」记录；有记录但没收到 → 收件方拦截
5. **锁定时价格已在阈值外**：纯穿越判定要求「由内侧跨到外侧」，此时需等价格
   回落内侧后再突破才触发 —— 面板标注「已在阈外·待回落穿越」
6. **确认只开了一个面板实例**（见 1.4）
7. 点顶部「触发中」统计卡，每行标注「已发信 HH:MM / 已在阈外·待回落穿越 /
   非交易时段·静默」，一眼看出卡在哪一层

### 8.3 状态标注

| 标注 | 含义 |
|---|---|
| 已发信 HH:MM | 15 分钟内已发送过 |
| 已在阈外·待回落穿越 | 价格已超阈但非穿越触发 |
| 非交易时段·静默 | 行情未更新，按闭市处理 |
