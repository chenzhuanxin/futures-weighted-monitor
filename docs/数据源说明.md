## 二、实时行情：天勤 TqSdk

### 2.1 什么是天勤

天勤（TqSdk）由**上海信易信息科技股份有限公司**（快期）出品，是国内主流的期货量化
数据 / 交易 SDK。本项目只用它的**行情**能力，不涉及交易。

* 官网：<https://www.shinnytech.com>
* 账号注册：<https://account.shinnytech.com>（免费）
* 依赖安装：`pip install tqsdk`

> ⚠ 清华源**没有** tqsdk 包。安装请用阿里源
> `-i https://mirrors.aliyun.com/pypi/simple/` 或豆瓣源。

### 2.2 架构：为什么放在独立线程

`TqApi` 是异步事件循环模型，必须持有一个线程不断 `wait_update()`。
本项目把它包进 `TqActor(threading.Thread)`：

```
HTTP 请求线程 ──投递任务──▶ 队列 ──▶ TqActor 线程
                                      │
                                      ├─ wait_update()
                                      └─ 把结果写回 Future
```

好处：HTTP 请求线程不阻塞；行情订阅集中管理；打包时无需处理多进程。

## 三、合约口径：加权（仓权）合约

### 3.1 合约标识

```
KQ.i@交易所.品种
```

例：`KQ.i@CZCE.SA`（郑商所纯碱加权）、`KQ.i@SHFE.cu`（上期所沪铜加权）

* `KQ` = 快期 / 天勤合成合约前缀
* `i` = **index，按持仓量加权**
* （对比：主连是 `KQ.m@`，本项目不使用）

### 3.2 加权方式

天勤按该品种**全部可交易月份合约的持仓量**做加权合成：

```
加权价 = Σ(合约价格 × 该合约持仓量) / Σ(持仓量)
```

因此它反映的是**品种整体价格水平**，而不是某一个合约的价格。
这也是本项目用它来跟「历史 H / L / M」做对比的原因。

### 3.3 真实月份合约

除加权外，面板还能查看**该品种全部在交易的真实月份合约**：

* 通过 `query_quotes(ins_class="FUTURE", exchange_id=…, product_id=…, expired=False)` 枚举
* **主力**：持仓量最大的合约，标橙色「主力」标签
* **已摘牌过滤**：`last <= 0` 的合约直接剔除（否则会出现价格为 0 的空合约）
* 合约中文名取天勤官方名称（避免郑商所「纯碱701 / 纯碱2701」这类显示差异）

## 四、历史基准 H / L / M

### 4.1 来源文件

```
C:/Users/gongq/Downloads/futures-daily-k-data/期货日K数据/汇总_全部品种.xlsx
```
（期货日 K 数据，2026-10 导出）

### 4.2 字段含义

| 字段 | 含义 | 用途 |
|---|---|---|
| **H** | 历史最高价 | 高侧偏离度分母基准 |
| **L** | 历史最低价 | 低侧偏离度分母基准 |
| **M** | 历史主连平均收盘价 | 偏离度 0 基准（中枢） |

### 4.3 快照数据已被内置

Excel 数值已内置进 `品种表.py`（93 个品种条目），运行时**不读取 Excel**，
因此无需携带原始文件即可运行。

### 4.4 已知缺陷与自动兜底（重要）

> ⚠ **碳酸锂（LC）/ 多晶硅（PS）/ 工业硅（SI）** 三个品种的原始日 K 导出被
> **截断**（只有 4~19 个交易日），其 H/L/M 明显失真
> （例如多晶硅会算出 **1903%** 这种无意义数字）。

处理办法：这 3 个品种 + 铂（PT）/ 钯（PD）/ 胶版纸（OP）共 **6 个**品种，
自动改用**加权合约全历史日 K 现算** H / L / M，界面上 `baseSrc=auto` 标识。

其余 **84 个**品种使用 Excel 数值（`baseSrc=excel`）。

### 4.5 自定义覆盖

支持导出为 JSON 修改后再导入，覆盖内置值（详见「使用说明」第七节）。

## 五、偏离度口径

以历史均价 M 为 0 基准，高低两侧各自归一化到 0~100：

| 侧 | 条件 | 公式 | 满格含义 |
|---|---|---|---|
| 高侧 | 现价 ≥ M | `(现价 − M) ÷ (H − M) × 100` | 触及历史最高 H = 100% |
| 低侧 | 现价 < M | `(现价 − M) ÷ (L − M) × 100` | 触及历史最低 L = 100% |

* 两侧都是「离开均价、走完该侧全程的比例」，越大越极端
* 现价越过 H / L 时会 > 100%（数值不截断，仅条长截断）
* 阈值刻度线画在同一条进度条上（同一把尺）

## 六、数据精度与局限

| 项 | 说明 |
|---|---|
| 延时 | 取决于网络与账号等级；面板实时显示实际延时值 |
| 日 K 深度 | 最深约 3600 根（大致自 2016 年前后起） |
| 订阅规模 | 86 品种实时行情刷新约 0.3 秒 |
| 僵尸品种 | 郑商所 普麦 / 强麦 / 早籼稻 / 粳稻 / 动力煤 为**零成交**品种，天勤仍按最后结算价维护报价，面板会展示但长期「休市」且永不预警 |
| 退市品种 | 7 个旧代码（ER / LR / ME / RO / TC / WS / WT）无加权合约，自动跳过 |
