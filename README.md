# futures-weighted-monitor

加权（仓权）合约监控面板 · 天勤 TqSdk 版

86 品种加权（仓权）行情 · Excel 历史基准偏离度 · 动态均线阈值 + 偏移 + 锁定 ·
1 分钟 K 线穿越预警 · 卡片式邮件 · SSE 实时跟随 · Ctrl+Z 隐身

> 跑在本机的期货全品种监控看板：把「当前价距历史极端位置有多远」量化成 0~100 的
> 偏离度，横向铺开 86 个品种，一眼看出谁在高位、谁在低位。

## 快速开始

### 方式 A：单文件 exe（推荐 · 免安装）

双击 `加权合约监控面板.exe`（91 MB），不依赖本机 Python / tqsdk。

1. 跳出黑色控制台窗口，**不要关**（关掉即退出服务）
2. 几秒后浏览器自动打开看板（默认 `http://127.0.0.1:8962/`）
3. 右上角「设置」→ 填写**天勤账号**与**邮件配置** → 开始监控

### 方式 B：源码运行

```bash
pip install tqsdk        # 唯一第三方依赖
双击 启动面板.bat         # 或 python launch.py
```

> 控制台会打印实际「看板地址」；端口被占用时自动顺延（8962 → 8963…）。

## 特性一览

- **只用加权（仓权）合约** `KQ.i@交易所.品种`，不使用主连
- **偏离度量化**：高侧 `(现价−M)/(H−M)×100`，低侧 `(M−现价)/(M−L)×100`
- **动态均线阈值**：周期 × 均线二级选择 + 0.1%~1% 上/下偏移，门槛 60%~90%
- **1 分钟 K 线穿越预警**，同根只报一次，非交易时段静默
- **卡片式邮件**（126 → QQ），无弹窗 / 无声音
- **SSE 实时推送**，无定时刷新，实时显示延时
- **Ctrl+Z 隐身**：整页变普通《通知》文档，标签标题同步改变
- **单实例保护**：重复启动复用已有实例，避免配置互相覆盖
